# AdventOfCode

This repository contains solutions for the advent of code written in TypeScript. 

## Running the solution

### Running all solutions

You are able to run all solutions for a specific year through the command `npm run solve:2026`. New years can be added through the `tsconfig.json`. 

### Running solutions for specific days

You are able to run solutions for specific days using the `npm run solve <folder containing index.ts>` i.e. `npm run solve src/2026/day01`
